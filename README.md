## About the Website

The Digital Intellia website was developed to establish the brand's online presence, showcase its services and provide visitors with a way to enquire about projects.

The website combines modern visual design, responsive layouts and interactive elements to create an engaging browsing experience.

## Technology Stack

- **ASP.NET Core MVC**

- **Razor**
- **HTML5**
- **CSS3**

## Website Features

- Responsive design for desktop, tablet and mobile.
- Interactive navigation and service carousel.
- Portfolio concepts showcasing website and dashboard designs.
- Project enquiry form with email integration.

- Search engine optimisation (SEO).

## Design Approach

Digital Intellia uses a modern blue-and-white visual identity, with clean layouts, thoughtful typography and interactive elements.
